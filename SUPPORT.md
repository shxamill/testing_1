# Support

For help with this HTML and Bootstrap practice pages:

- Check the README and existing issues first.
- Open an issue for a reproducible defect or a focused improvement.
- Include your browser, operating system, steps to reproduce, and any relevant error message.
- Include screenshots for visual issues where useful.

Do not post passwords, tokens, personal information, or unredacted logs. This is a personal learning project; support is provided on a best-effort basis.

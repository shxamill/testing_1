# Contributing

This repository contains small HTML and Bootstrap practice exercises.

## Guidelines

- Keep each exercise self-contained and easy for a beginner to follow.
- Use semantic HTML and labels for form controls.
- Do not imply that a visual-only form performs authentication or stores information.
- Do not commit passwords, API keys, local editor files, or generated output.

## Verify changes

Open index.html and web/index.html in a browser. Check that the layout remains usable at desktop and mobile widths. There is no build system or automated test suite.

## Pull requests

Describe the exercise or component changed and include a screenshot for visible UI changes when useful.

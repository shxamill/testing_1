# Code of Conduct

This HTML and Bootstrap practice pages should remain a respectful and constructive place to learn and collaborate.

## Expected behavior

- Be respectful and considerate.
- Focus feedback on code and ideas, not people.
- Explain disagreements calmly and welcome different experience levels.
- Do not harass, discriminate against, intimidate, or expose private information about others.

## Reporting and enforcement

Report conduct concerns privately through the maintainer's GitHub profile: https://github.com/shxamill. The maintainer may remove inappropriate content or restrict participation when necessary.

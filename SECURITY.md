# Security Policy

## Scope

This repository contains static front-end learning material. It does not provide a production authentication, payment, account, or customer-data service.

## Reporting

Do not publish credentials, private information, or exploit details in a public issue. Report a security concern privately through https://github.com/shxamill and include the affected file, impact, and reproduction steps. Redact secrets and personal data.

Please allow the maintainer a reasonable opportunity to investigate before making a report public.
